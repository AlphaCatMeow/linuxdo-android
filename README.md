## 🌟 核心优势与功能特性

### 1. 🛡️ 原生 DoH + ECH TLS 安全直连（免代理突破阻断）

- **真·加密直连**：基于原生二进制网络层，全面支持 **DoH (RFC 8484)** 与 **ECH (RFC 9460)** 加密 ClientHello，彻底隐藏 SNI 目标域名，国内网络直连访问不阻断。
- **预置多路优选节点**：内置国内三网优选直连节点（如 L 站专属优选节点等），支持多路端到端真实测速与毫秒级延迟展示。
- **高可用容灾与代次自愈**：主节点异常时秒级自动代次故障转移，并具备系统底层 DNS 兜底保护。
- **智能 VPN / 代理感知**：检测到系统开启 VPN 或代理软件时，自动平滑暂停 DoH 并直接走系统代理，免除分流冲突。

### 2. 🔒 核心会话长效稳定不掉盾

- **精准解耦凭据架构**：严格遵循 Cloudflare 验证指纹规范，将论坛账号会话（`_t`）与设备级过盾指纹凭证（`cf_clearance`）精准解耦置换，彻底攻克 `CSRF 403` 与频繁跳盾难题。
- **安全挑战无缝闭环**：偶发人机验证在独立安全弹层内无感闭环，并通过连续静默探测自动重放业务请求，日常刷帖告别 CF 盾死循环与转圈。

### 3. 🔔 本地推送通知与桌面未读角标

- **高可靠 REST 守护轮询**：全面切换为短 WakeLock 保护的轻量轮询守护，告别死锁风险与连接断流。

- **多维保活与唤醒链路**：支持「亮屏抢跑即刻拉取 + 退回桌面即时刷新 + 息屏硬件阶梯闹钟」，强力穿透各品牌国产系统（MIUI/HyperOS、HarmonyOS、MagicOS、ColorOS、OriginOS 等）的后台冻结。

### 4. ✍️ 全能创作发布与互动升级

- **支持发布新话题**：完整支持选择主/子分类、标签（Tags）、标题输入、正文撰写与附件上传。
- **所见即所得图文混排编辑**：评论与发帖支持所见即所得编辑器，支持 Markdown 语法快捷插入、原生图片插入及缩略图快速移除。

- **贴内表情选择器**：优化 Emoji 表情选择器交互体验，输入互动更加随心。
- **楼层全套操作与书签系统**：支持楼层链接一键复制、书签收藏/取消收藏、编辑、删除与举报等全套 Discourse 原生操作。

### 5. 📌 个性化定制与版块管理

- **分类自定义排序（把常用的统统放前面）**：在“分类”页面直接**长按卡片即可自由拖拽调整顺序**，随心将日常高频访问的「开发调优」、「搞七捻三」、「福利羊毛」、「人工智能」等核心板块统统置顶在前；排序结果本地自动持久化保存，重启依然生效，并支持右上角菜单一键恢复官方默认顺序。
- **关注版块双向实时同步**：自选关注版块与 L 站 Web 端双向实时同步（移动端修改同步至 Web，Web 改动实时回流），多端无缝协同。
- **话题 4 档通知级别（支持免打扰屏蔽）**：支持单帖精细化设置「关注 / 跟踪 / 常规 / 免打扰（Muted）」，彻底屏蔽不想关注的话题动态。

### 6. 🚀 应用内流式无感更新

- **安全与流式体验**：原生流式下载进度实时展示，支持 SHA256 哈希完整性自动校验，下载完成一键无缝拉起系统安装器。

### 7. 💎 纯正原生开发与细节打磨

- **Kotlin + Jetpack Compose 全原生构建**：拒绝套壳，包体轻盈；全屏跟手侧滑返回动效，本地分类缓存预热实现冷启动秒开。
- **外观与主题**：完美适配浅色 / 深色 / 跟随系统三档外观切换。
- **站长专属彩蛋**：定制站长 neo 专属方形头像展示，深度致敬L站社区。
- **全能安全登录**：支持账号密码 / 邮箱验证码登录、**2FA 两步验证（TOTP 动态口令与恢复码）**、L 站风控网页授权一键认证。
